Munu is designed for systems where correctness is not optional — AI agents that must obey constraints, firmware that must not crash, networks that must converge, and edge functions that must respond in time.

AI Agent Supervision

Contracts as guardrails for LLMs at tool-use time

When an LLM calls a tool, that call is a contract — every LLM in your stack reads the same constraint. The must: formula defines what the agent is allowed to do. The do: formula defines how it recovers from failure. Breach is not an exception — it's a permanent signal to the supervisor that the agent violated its obligation.

Why Munu
  • Formal bounds on agent behaviour — not just prompt engineering
  • Supervision trees that escalate, restart, or terminate agents
  • Structured diagnostics that LLMs can parse and self-correct from
  • Compose agent capabilities via lattice subsumption (⊑)
agent.uv 
contract Agent(tools: ToolSet) {
  must: only_calls(tools.allowed)
    and responds_within(5s)
    and output_satisfies(safety_filter)

  do: two_strikes()   // restart once, then escalate

  nu serve(requests: Stream<Query>) {
    let result = tools.call(requests.head)
    emit(result)
    serve(requests.tail)
  }
}

Embedded Systems

Verified firmware on Cortex-M0 and RISC-V

Munu's kernel runs without an OS, without a heap, without a garbage collector. Contracts compile to bare-metal bytecode with static memory allocation. The requires/ensures/decreases clauses prove termination and correctness at compile time — critical for safety-rated firmware.

Why Munu
  • No runtime overhead — arena allocation, no GC pauses
  • Compile-time verification of timing and memory bounds
  • Same language for application logic and hardware drivers
  • Supervision trees replace ad-hoc watchdog timers
sensor.uv · target=cortex-m0 
contract SensorDriver(bus: I2C) {
  must: responds_within(10ms)
    and never_blocks(bus)

  do: permanent()   // always restart on failure

  mu read_temperature() -> i16
    requires bus.is_ready()
    ensures  (t) t >= -40 && t <= 125
  {
    let raw = bus.read_register(0x00, 2)
    (raw[0] << 8 | raw[1]) / 256
  }
}

Distributed Consensus

BlackFrame protocol for trustless coordination

Contracts that span multiple nodes communicate via BlackFrame — a fixed-size encrypted frame protocol. Routing is greedy on the Poincaré disk. State convergence uses CRDTs backed by Datalog, ensuring monotone progress without coordination overhead.

Why Munu
  • Fixed 1024-byte frames eliminate framing attacks
  • Hyperbolic routing with O(log n) stretch
  • CRDT + Datalog for coordination-free convergence
  • Contract obligations enforced across network boundaries
replica.uv 
contract ReplicaNode(peers: Set<NodeId>) {
  must: converges_within(peers, 30s)
    and frame_size_eq(1024)

  do: permanent()

  nu replicate(events: Stream<Event>) {
    let frame = BlackFrame::seal(events.head)
    for peer in peers {
      route(frame, peer.coordinates)
    }
    replicate(events.tail)
  }
}

Edge Computing

WASM contracts in browsers and CDN workers

Munu contracts compile to WebAssembly with zero runtime dependencies. Deploy the same verified logic to Cloudflare Workers, Deno Deploy, or a browser tab. The WASI host provides I/O — the contract never touches the network directly.

Why Munu
  • Sub-millisecond cold starts — no interpreter warmup
  • Same contract runs in browser, CDN edge, and server
  • Sandboxed by WASM — no memory safety concerns
  • Module-per-contract with aggressive dead-code elimination
edge.uv · target=wasm 
contract EdgeValidator(config: Config) {
  must: latency_p99_under(5ms)
    and memory_under(128kb)

  do: permanent()

  mu validate_request(req: HttpRequest) -> Response
    requires req.body.len <= config.max_body
    ensures  (r) r.status < 500
  {
    let parsed = parse_json(req.body)?
    let checked = schema_check(parsed, config.schema)
    Response::ok(checked)
  }
}

Formal Verification

Prove properties at compile time, not test time

Every mu function carries requires/ensures/decreases annotations. The compiler verifies termination, pre-conditions, and post-conditions statically. No separate proof assistant needed — verification is part of the language, not bolted on.

Why Munu
  • Termination proofs via decreases measures
  • Pre/post conditions checked at compile time
  • Lattice-based type inference catches contradictions early
  • No separate proof language — verification in the source
search.uv 
mu binary_search(arr: &[i64], target: i64) -> Option<usize>
  requires arr.is_sorted()
  ensures  (r) match r {
    Some(i) => arr[i] == target,
    None    => !arr.contains(target)
  }
  decreases arr.len
{
  if arr.is_empty() { return None }
  let mid = arr.len / 2
  match arr[mid].cmp(target) {
    Equal   => Some(mid),
    Less    => binary_search(&arr[mid+1..], target),
    Greater => binary_search(&arr[..mid], target),
  }
}
