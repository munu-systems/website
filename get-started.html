Quick Start

Get started with Munu.

Install the compiler, create your first project, and run a contract — in under five minutes.

What You Get

Three commands cover the full workflow — from source to verified deployment.

compile Verify contracts and emit bytecode 
munu compile hello.uv
run Compile and execute on the dataflow VM 
munu run hello.uv
node Boot a network node from a signed manifest 
munu node manifest.bin

Installation

Build from source — requires Rust 1.75+ 
git clone https://github.com/munu-systems/munu.git
cd munu
cargo build --release

Your First Project

01 Write a contract 
// hello.uv
mu greet(msg: Msg) -> Msg {
  msg => msg
}

pub contract Hello(msg: Msg) -> [Msg]
    behaviour {
        do: nu X. [_] X
        must: true
    }
{ greet(msg) }
02 Compile it 
# compile and print summary
munu compile hello.uv
03 Run it 
# compile and run on the dataflow VM
munu run hello.uv

Deployment Targets

The kernel is no_std by design. The same bytecode runs anywhere the kernel can be embedded.

host

Desktop / Server

Compile and run directly with the CLI. Embed the kernel as a Rust crate in any project.

munu run hello.uv
no_std

Embedded

The kernel requires no OS, no heap, no allocator. Cooperative scheduling on bare metal.

cargo add munu-kernel --no-default-features
node

Distributed

Boot a network node from a binary manifest. Ed25519 signed deployment cascades across peers.

munu node manifest.bin
