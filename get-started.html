Quick Start

Get started with Munu.

Install the compiler, create your first project, and run a contract — in under five minutes.

Installation

Option 1 — Install script (recommended) 
curl -sSL munu.dev/install | sh
Option 2 — Build from source 
# requires Rust 1.75+
git clone https://github.com/munu-systems/munu.git
cd munu
cargo build --release
cargo install --path crates/munu-cli
Option 3 — Cargo install 
cargo install munu-cli
Verify your installation: munu --version

Your First Project

01 Create a new project 
munu new hello-world
cd hello-world
02 Project structure 
# generated project layout
hello-world/
├── munu.toml         # project manifest
├── src/
│   └── main.uv       # entry contract
└── tests/
    └── main_test.uv  # contract tests
03 Write a contract 
// src/main.uv
contract Hello {
  do: permanent()

  mu greet(name: String) -> String
    requires name.len > 0
    ensures  (r) r.contains(name)
  {
    "Hello, " ++ name ++ "!"
  }
}
04 Run it 
# run natively
munu run

# run as WASM
munu run --target=wasm

# check types and contracts
munu check

# run tests
munu test

Deployment Targets

Munu compiles to three targets from day one. The same contract, the same verification — different backends.

native

Native / Rust

Compiles to a Rust crate. Embed in any Rust project or run standalone. Supports no_std.

munu build --target=native
wasm

WebAssembly

WASI or browser host. Module-per-contract with dead-code elimination.

munu build --target=wasm
mcu

Microcontroller

ARM Cortex-M0, RISC-V 32-bit. No heap, no OS, cooperative scheduling.

munu build --target=mcu:cortex-m0
